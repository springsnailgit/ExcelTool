# Excel表格对比工具

## 功能特点
- 基于指定列进行精确行匹配
- 只比对两表共有的列，忽略独有列
- 智能处理数据类型差异
- 竖排排列，差异数据红色粗体高亮显示
- 支持手动排除不需要的列

## 安装和使用

### 安装依赖
```bash
pip install -r requirements.txt
```

### 启动程序
```bash
python excel_compare_improved.py
```

## 使用说明

1. **选择主对比表格** - 作为基准的Excel文件
2. **选择关键列** - 用于行匹配的列（如ID、编号等）
3. **设置排除列**（可选） - 在高级选项中输入不想要的列名，用英文逗号分隔
4. **添加待对比文件** - 可以添加多个Excel文件
5. **选择输出目录** - 结果文件保存位置
6. **开始对比** - 自动生成差异报告

## 输出结果

- 生成带时间戳的Excel差异报告
- 浅蓝色行：主表格数据
- 白色行：对比表格数据  
- 红色粗体：存在差异的数据列
- 每两行为一组差异对比记录
