## 常见问题

### Q: 为什么某些列没有出现在结果中？
A: 只有主表格与对比文件都包含的列才会参与对比，独有列会被自动排除。

### Q: 关键列可以取消选择吗？
A: 不可以，关键列是行匹配的基础，必须参与对比。

### Q: 如何处理数值类型不一致的问题？
A: 工具会自动标准化数据，如将字符串"100"与数值100视为相同。

### Q: 支持哪些Excel格式？
A: 支持.xlsx和.xls格式，推荐使用.xlsx格式以获得最佳兼容性。

## v4.0.1 - 共同列检测修复

### 问题描述

在使用"比对列选择"功能时，点击"选择比对列"按钮后弹出窗口显示"主表格与对比文件没有共同列"的错误，导致无法正常选择参与对比的列。

### 问题原因分析

#### 原有逻辑缺陷

```python
# 原有的错误逻辑
for file_path in compare_files:
    excel_file = pd.ExcelFile(file_path)
    for sheet_name in excel_file.sheet_names:  # ❌ 对每个工作表都取交集
        compare_df = pd.read_excel(file_path, sheet_name=sheet_name)
        compare_columns = set(compare_df.columns)
        common_columns = common_columns & compare_columns
```

#### 问题本质

1. **多工作表交集问题**：
   - 原方法对每个文件的**每个工作表**都取交集
   - 如果文件包含多个工作表且列结构不完全相同
   - 最终交集可能变成**空集**

2. **逻辑不一致**：
   - 共同列检测使用所有工作表
   - 但实际对比时只使用第一个工作表
   - 两者逻辑不匹配

### 修复方案

#### 核心修复

```python
# 修复后的正确逻辑
for file_path in compare_files:
    excel_file = pd.ExcelFile(file_path)
    sheet_names = excel_file.sheet_names
    if sheet_names:
        first_sheet = sheet_names[0]  # ✅ 只使用第一个工作表
        compare_df = pd.read_excel(file_path, sheet_name=first_sheet)
        compare_columns = set(compare_df.columns)
        common_columns = common_columns & compare_columns
```

#### 修复原则

1. **逻辑一致性**：与实际对比算法保持完全一致
2. **只用首表**：每个文件只使用第一个工作表
3. **提前退出**：如果交集为空，立即停止处理
4. **错误处理**：文件读取失败时跳过继续处理

#### 测试验证

**测试数据**
- **主表格**：103列
- **对比文件**：14列  
- **实际共同列**：11列

**修复前**

## v4.1 - 界面布局全面优化

### 优化概述

实现了界面布局的全面优化，包括显示改进、功能增强和布局重新设计，显著提升了用户体验和操作效率。

#### 显示改进

**中文确认对话框**
- **优化前**: 使用系统默认的"Yes"/"No"按钮
- **优化后**: 自定义中文确认对话框，使用"是"/"否"按钮
- **改进功能**:
  - 重置确认："确定要重置所有输入和状态吗？" - [是] [否]
  - 清空确认："确定要清空所有待对比文件吗？" - [是] [否]
  - 400x150像素居中弹窗，更好的用户体验

**增强数据来源命名**
- **优化前**: `文件名_主表格` / `文件名_对比表格`
- **优化后**: `文件名_工作表名_主表格` / `文件名_工作表名_对比表格`
- **改进效果**:
  - 数据来源信息更加完整准确
  - 便于用户识别具体的工作表来源
  - 支持多工作表文件的精确溯源

**优化差异报告排列顺序**
- **优化前**: 数据排列可能出现混乱
- **优化后**: 严格按照"蓝白蓝白"的排列顺序
- **实现方式**:
  - 按关键列值分组重新排序
  - 每组内先主表格记录（蓝色背景）后对比表格记录（白色背景）
  - 整体呈现规律的蓝白相间效果

#### 界面布局优化

**并排布局设计**

```
├─ 关键列选择             ├─ [待对比文件] | [比对设置]
├─ 待对比文件             │   └─ 比对列选择（上）
```
